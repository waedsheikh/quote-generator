# 🌟 React Quote Generator

A simple, lightweight, and responsive Random Quote Generator web application built with React.js and styled with modern CSS. It fetches inspiring quotes dynamically from a public API.

🔗 Live Demo: [https://waedsheikh.github.io/quote-generator/](https://waedsheikh.github.io/quote-generator/)

---

## 🚀 Features

* Dynamic API Integration: Fetches fresh random quotes and authors instantly using fetch and async/await from DummyJSON API.
* Loading State: Displays a smooth loading indicator while fetching new quotes.
* Responsive Design: Clean, centered, and modern UI that looks great on all screens.
* React Hooks: Utilizes useState for state management and useEffect for lifecycle handling.

---

## 🛠️ Built With

* React.js (Vite)
* CSS3
* DummyJSON Quotes API
* GitHub Pages (Deployment)
